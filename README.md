# Rapido Customer Service

## Overview
Customer Service is a backend microservice developed using Java and Spring Boot for a ride-booking application. It handles customer-related operations.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- REST APIs
- Maven
- Docker
- Postman

## Features
- Customer registration and management
- REST API development for customer operations
- Customer data persistence using PostgreSQL
- Customer-related business logic
- API testing using Postman

## Architecture
This service is part of a microservices-based ride-booking project. It works alongside other services, including Rider Service.

## How to Run
1. Clone the repository.
2. Configure the PostgreSQL database connection in the application configuration.
3. Ensure PostgreSQL is running and the required database exists.
4. Run the Spring Boot application.
