# Rapido Customer Service

## Overview
Customer Service is a backend microservice for a ride-booking application developed using Java and Spring Boot. It manages customer-related operations and supports the ride-booking workflow.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- REST APIs
- Maven
- Postman
- Docker

## Features
- Customer registration and management
- REST API development for customer operations
- Customer data persistence using PostgreSQL
- Integration with the ride-booking workflow
- API testing using Postman

## Project Structure
This service is part of a microservices-based ride-booking project.

## Setup
1. Clone this repository.
2. Configure your PostgreSQL connection in the application configuration.
3. Ensure the required database exists.
4. Run the Spring Boot application.

## API Testing
Use Postman to test the available customer endpoints.
